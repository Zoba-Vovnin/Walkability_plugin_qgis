# Walkability – плагин для QGIS

**Анализ пешеходной доступности городской среды**  
Совместим с QGIS 3.x и QGIS 4.x (PyQt5 / PyQt6)

## Описание

Плагин **Walkability** предназначен для оценки пешеходной связанности элементов городской инфраструктуры. Он строит граф дорожной сети, учитывает физические характеристики улиц (ширина, тип покрытия), плотность населения и близость к зелёным зонам, а затем рассчитывает кратчайшие (по взвешенной метрике) маршруты от заданных начальных точек до ближайших конечных точек.

Результаты экспортируются в GeoJSON и могут быть сразу добавлены в проект QGIS.

**Ключевая особенность**: расчёт всегда выполняется в метрической проекции EPSG:3857, что гарантирует корректные значения длины в метрах независимо от исходных систем координат данных.

## Возможности

- Импорт дорожной сети, стартовых и финишных точек, слоёв плотности и парков.
- Поддержка множества форматов: GeoPackage, Shapefile, GeoJSON, GML, KML, KMZ, MapInfo TAB, SQLite, File Geodatabase.
- Автоматическая перепроекция всех слоёв в EPSG:3857 для точных метрических расчётов.
- Учёт параметров улиц:
  - **ширина** (чем уже, тем выше «штраф»);
  - **тип покрытия** (асфальт, брусчатка, грунт и др.);
  - **плотность населения** (высокая плотность снижает вес ребра вблизи соответствующей точки);
  - **близость к паркам / водным объектам** (краевой эффект – рёбра, попадающие в буфер 8 м, получают понижающий коэффициент).
- Интеллектуальная вставка точек старта/финиша в граф: точки проецируются на ближайшее ребро, ребро разбивается с сохранением весовых характеристик.
- Поиск кратчайшего пути от каждой начальной точки к **ближайшей** конечной точке с помощью алгоритма Дейкстры.
- Экспорт результатов:
  - слой стартовых точек (GeoJSON);
  - слой конечных точек (GeoJSON);
  - слой рассчитанных маршрутов с атрибутами: вес, длина (метры), время в пути (мин), количество вершин;
  - файл метаданных `metadata.json`.
- Опциональное добавление слоёв результатов в текущий проект QGIS.
- Фоновое выполнение расчёта через `QgsTask` – интерфейс не блокируется.
- Подробное логирование в файл `walkability.log` внутри выходной папки.
